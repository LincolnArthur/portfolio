    SOBRE MIM

    Estudo Engenharia de Computação na UNIVASF, em Juazeiro (BA), e também curso Direito na Unibras. Programo em C, Java e Python.

    Aqui estão meus projetos: o Eixo 0, um jogo que estou fazendo em Java, e os das disciplinas do curso, em C: um jogo de fazenda feito com raylib, que dá para jogar aqui mesmo no navegador, um programa que encontra a saída de labirintos e um pequeno interpretador de Prolog.

    PROJETOS

    2026

    Eixo 0 | Projeto pessoal, versão barebones | Java 17 e Maven

    • Versão simplificada do meu jogo Eixo 0, escrita para praticar orientação a objetos: 27 classes organizadas em pacotes de mundo e personagens.
    • Classes abstratas e interfaces para personagens, inimigos (corpo a corpo, voador e de longo alcance), armas e habilidades com custo de energia e tempo de recarga.
    • Inventário, sistema de nível e experiência, e mapa de salas indexado por id com LinkedHashMap.

    2026

    maze-solver-bfs | Algoritmos e Estruturas de Dados | UNIVASF

    • Implementei busca em largura com fila sequencial e matrizes de visitados e de pais para reconstruir o menor caminho até a saída.
    • Animação passo a passo no terminal com cores ANSI e leitura de 10 labirintos a partir de arquivos de texto.
    • Projeto em dupla com Caio Benevides.
    • Código no GitHub

    2026

    prolog-simulator-c | Algoritmos e Estruturas de Dados | UNIVASF

    • Construí um interpretador no estilo Prolog com parser de fatos e regras, predicados indexados em árvore binária de busca e cláusulas em listas encadeadas.
    • Motor de resolução com unificação, renomeação de variáveis e backtracking, que encontra todas as soluções de uma consulta.
    • Bancos de conhecimento carregados de arquivos .txt. Projeto em dupla com Caio Benevides.
    • Código no GitHub

    2025

    raylib-farm | Algoritmos e Programação | UNIVASF

    • Desenvolvi um jogo de fazenda 2D em C com raylib: loja com rolagem, inventário, plantação em grid com crescimento por tempo e sistema de XP e níveis.
    • Publiquei uma versão que roda no navegador (WebAssembly) e executáveis para Windows e Linux que não exigem instalar a raylib.
    • Na revisão do projeto, corrigi 4 bugs, entre eles uma falha que permitia gerar dinheiro infinito.
    • Jogar no navegador
    • Baixar para Windows e Linux
    • Código no GitHub
